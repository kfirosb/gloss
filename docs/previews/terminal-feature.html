Run shows on blocks tagged shell, bash, zsh, console or terminal, or with no tag. A block tagged TypeScript, JSON or similar only gets Copy code. A leading “$ ” is stripped. The folder's idle terminal is reused; if it is busy, Run opens “Terminal 2”.

3 · The terminal popupThe default view. Opens on Run and on clicking a terminal tab. Close returns to the conversation; the terminal keeps running. Expand switches to the full-workspace view and remembers the choice.

5 · The settingSettings → Sessions. Expand and Shrink change it too, so the view you used last is the one you get next time.

Sessions

Applies to sessions started from Gloss
Run and terminal tabs use this view. Expand and Shrink in the terminal update it.

Also in the design, not pictured: terminals survive an app restart like sessions do; a shell that exits disappears from the tab row and has no Saved entry; nothing runs without your click and Run runs exactly the text shown; an empty First message is rejected because the prompt is what lets Gloss connect.
