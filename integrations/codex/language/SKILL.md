description: Use when the user asks to discuss or prepare coding instructions in another language while staying attached to this Codex session.

Start the local Gloss app with `CODEX_THREAD_ID` or `CODEX_SESSION_ID` from the current session and the requested language argument. In Codex, invoke this skill explicitly as `$language hebrew` or through `/skills`; the product surface remains `/language hebrew` conceptually.

The assistant is a separate conversation. Discussion and preparation never send a coding instruction. Delivery happens only after the user reviews the exact English draft and presses the destination-specific Send button. Native Codex approvals remain in Codex.
