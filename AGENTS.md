# Release work

For requests to update the Mac app, create a new version, or build a DMG, read and follow [docs/mac-release-protocol.md](docs/mac-release-protocol.md).

This is a local Git repository. Use local `main` as the source of updates; do not assume a remote or online publishing destination. Preserve the running app and saved data while preparing a release. Repository-root DMGs and other unrelated untracked files are not source changes to stage.
